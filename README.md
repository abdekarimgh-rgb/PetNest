À propos du projet
PetNest est une plateforme d’animalerie en ligne qui réunit la vente de produits pour animaux, l’adoption responsable et la réservation de services. L’objectif est de créer un site web statique, responsive et accessible à partir d’une maquette Figma, afin de faciliter la navigation et de présenter les informations de manière claire.

Maquette Figma

Pages
Accueil : Présenter PetNest, les produits vedettes, les animaux à adopter et les marques partenaires.

Catalogue : Afficher les produits avec leurs images, leurs noms et leurs prix, avec des options de filtrage et de tri.

Détail produit : Présenter les informations d’un produit, sa galerie d’images, sa description, les avis et un formulaire pour laisser un avis.

Adoption : Présenter le principe de l’adoption responsable, les animaux disponibles et un formulaire de demande d’adoption.

Services et contact : Présenter les services et leurs tarifs, une FAQ, un formulaire de prise de rendez-vous, les coordonnées et les réseaux sociaux.

Technologies utilisées
HTML5 : Pour structurer les pages avec des balises sémantiques.

CSS3 : Pour la mise en page, le design et le responsive design.

Git et GitHub : Pour versionner le code et faciliter le travail en équipe.

GitHub Projects : Pour organiser les tâches et suivre l’avancement du projet.

GitHub Pages : Pour héberger le site en ligne.

Fonctionnalités
Navigation entre les différentes pages.
Design cohérent avec la maquette Figma.
Affichage responsive sur ordinateur, tablette et smartphone.
Grilles de produits et d’animaux.
Filtrage et tri des produits dans le catalogue.
Galerie d’images sur la page détail produit.
Formulaires d’avis, d’adoption, de newsletter et de rendez-vous.
FAQ sous forme d’accordéon.
Messages d’erreur pour les champs de formulaire invalides.
Header et footer communs aux pages.
Prise en compte de l’accessibilité et du référencement naturel (SEO).
